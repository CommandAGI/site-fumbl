# site-fumbl

The site of Fumbl, a dating app for adults built safety first, a company of CommandAGI (`org-fumbl`). A static folder
served by CommandAGI's site hosting; mounted in the CommandAGI repository at
`seed/drive/platform/org-fumbl/sites/fumbl`. Live at <https://fumbl.commandagi.app>.

- `index.html`, `safety.html`, `about.html`: the site. The safety notice, tips and rules are the charter's
  (`companies/fumbl/charter.md` in CommandAGI's Drive).
- `app/`: the demo. Fictional sample profiles drawn as illustrations, each marked "Sample profile"; the state is in the
  browser's session storage and the page sends nothing (`connect-src 'none'`).
- `app/live.html`, `app/live.js`: the live app for real members. It signs a member in with their CommandAGI account
  (OAuth with PKCE, the client `fumbl`) and calls the api worker's `/fumbl/*` routes (`src/data/fumbl.ts` in the
  CommandAGI repository); its policy reaches only the api origins. On `127.0.0.1` or `*.localhost`, `?api=` points it
  at another api (the browser journey `tests/workbench/browser_company_apps.mjs` serves Fumbl's routes there).
- `terms.html`, `privacy.html`: the terms of use and the privacy notice.
- `team.html`, `team-*.html`, `people/`: made by `node scripts/seed/people/personas.mjs` in the CommandAGI repository.
  The team are disclosed AI agents.

## the languages

English at `/`, Spanish at `/es/`, Simplified Chinese at `/zh/`: the static-locale mechanism of CommandAGI's public
sites (`docs/sites.md` § locales, in CommandAGI). `locales.json` is the one list: the locales, their prefixes, their own
names and their few words, the pages, which pages each locale translates, and the domain → locale record (Fumbl owns no
domain yet; `fumbl.commandagi.app` is the primary, in English).

- A page a locale translates (`es/`, `zh/`: `index.html`, `safety.html`) is written by hand: its own words, its own
  `<html lang>`, a canonical to itself, and an alternate for each language.
- A page a locale does not translate yet (`about`, `terms`, `privacy`) is generated by `make-locales.mjs`: the English
  page under the locale's prefix, its links lifted one folder, a note that says it is English, and a canonical to the
  English page, so no search engine sees a second copy. The generated file is committed; the site stays a plain static
  folder that site hosting serves with no build.
- Every page has the **A/文** button in the footer, which opens one dialog with a row per language, each in its own
  name, the current one checked. It works without script (invoker commands); `locale.js` remembers the choice, closes
  the dialog where the commands are missing, and shows the language hint to a browser that reads another of the page's
  languages. `zh` without the Hans script or a simplified-Chinese region (CN, SG, MY) never picks zh-Hans.
- The safety page keeps the English notice in bold capitals, as Texas Bus. & Com. Code 106.004 and N.J.S.A. 56:8-171
  ask, above its translation.
- The terms and the privacy notice are English (counsel reviews them); the demo and the live app are English; the
  team pages are English, made by the personas script.

```
node make-locales.mjs           regenerate the pages a locale does not translate
node make-locales.mjs --check   fail when one of them is stale
node --test locale.test.mjs     the site's own test: every page in every locale, the picker, the links, no outside request
```

## deploy

`commandagi sites deploy . --prod` from this folder, with the account signed in on the computer (the site is
`Sites/Fumbl` on the login's Drive; a seed also publishes `org-fumbl`'s `sites/fumbl`). Custom domains are the owner's:
`commandagi sites domains fumbl add <domain>` prints the CNAME and TXT records to add.

`live.html` is served by CommandAGI's api worker at `/fumbl/*`. That is a CommandAGI-internal surface for this one
company, not CommandAGI's public API: a real backend of Fumbl's own would own the members, likes, matches, messages,
blocks and reports, the age-check webhook and the report queue, and the site would call it as any third-party API.
